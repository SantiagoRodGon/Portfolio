OECD Mock Quiz Project

Skills gained: Programming (Python)

The OECD Mock Test project focused on the development of an interactive digital assessment platform designed to simulate international standardized exams and analyze student performance through automated scoring and data visualization. The objective was to create a system capable of replicating the structure and timing of PISA-style evaluations while generating useful feedback metrics for teachers and learners.

The program was developed using Python, where I implemented question banks, randomized test sequences, and automatic evaluation based on user input. Each test session generated a performance dataset that was processed to calculate accuracy, completion time, and question difficulty correlation. These results were then visualized through dynamically generated graphs, providing immediate insights into student progress and knowledge gaps.

The final version of the OECD Mock Test successfully replicated key components of a digital testing environment and demonstrated how lightweight code architecture can support real-time assessment. Future improvements include implementing web-based functionality, user authentication, and a database-driven analytics system to handle larger datasets and remote access. This project represents a blend of programming, data processing, and system design aimed at improving how learning outcomes are measured and understood.
